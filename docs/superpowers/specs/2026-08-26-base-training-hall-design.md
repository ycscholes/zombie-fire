# 基地历练大厅任务设计

## 目标

为 `zombie_click.py` 增加一条 `base-training-hall` 命令，完成基地页下历练大厅的战场争霸与元素试炼免费任务，并在结束时返回基地页面。

## 范围与流程

命令从已校验的游戏窗口开始：

1. 点击基地 tab，进入基地页面。
2. 点击历练大厅并滚动到底部，露出战场争霸与元素试炼。
3. 战场争霸：打开挑战，选择左下角城堡，再次挑战；对弹窗第一项执行五次扫荡，每次领取后取消奖励弹窗；关闭挑战弹窗并返回历练大厅。
4. 元素试炼：打开挑战，进入核心试炼；打开挂机弹窗并领取免费奖励，取消弹窗；执行一次免费扫荡；依次返回核心试炼、元素试炼、历练大厅和基地。

## 实现边界

- 使用现有固定坐标点击器，统一保持移动、按下、80ms、click-state=1释放和0.5–1.0秒普通间隔。
- 首次页面定位和关键状态由 Computer Use 确认；历练大厅滚动由脚本向已校准画布投递连续 CoreGraphics 拖拽手势。
- 只执行明确的免费挑战、领取和扫荡；按钮文字或费用不明确时停止，不尝试钻石、广告或付费项。
- 命令支持 `--battle-times`，默认值为5，并支持 `--dry-run` 与现有窗口校验参数。

## 错误处理与验证

命令在每个主要页面进入前保持现有窗口校验；点击失败时按现有 helper 的 fail-closed 规则退出。自动测试验证命令注册、默认次数、动作顺序、滚动动作和 dry-run 不产生点击；真实成功以 Computer Use 可见页面状态和游戏奖励/完成状态为准。
