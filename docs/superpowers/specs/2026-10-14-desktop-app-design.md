# 向僵尸开炮桌面 App 设计

## 目标与交付
交付本机 macOS 可双击启动的中文 .app、源码、构建入口和使用说明。采用 Tauri 2 + Web 界面与 Python sidecar 执行层；不引入 Electron 服务。首版交付 macOS，保留 Windows 界面与调度复用的路径。现有 CLI 保持兼容。首次交付面向当前 macOS，不承诺未经验证的其他电脑环境。

## 界面与执行
- 单独命令：选择现有命令，编辑该命令支持的参数，显示用途与入口页面，支持执行和模拟运行。使用参数数组启动进程，不拼接 shell 命令。
- 每日任务：默认覆盖当前 daily-rewards 的 8 阶段、22 个业务任务。用户可从现有任务目录添加、移除或启用/禁用任务，保存配置并恢复默认。添加任务指组合已有操作，不包含录制新坐标或编写新业务流程。
- 顺序：保持现有阶段与子任务顺序；新增、移除任务时补齐必要导航，不把前置业务奖励领取作为导航重复执行。军团征途礼物保持军团最后一步。
- 起始任务：下拉选择任一启用任务，展示需要的游戏页面，只运行该任务及后续启用任务。中断后保留最后正在执行的任务，用户可重新选择起点；任务内不恢复到某一次点击或循环中间。
- 开始/停止：同一时刻只允许一个执行进程，重复启动被阻止。停止取消后续任务与输入；已发出的物理输入无法撤销。退出 App 时结束本 App 启动的执行进程，不能遗留后台点击。
- 实时显示当前任务、运行状态与日志，区分执行结束、失败、停止、模拟完成。脚本结束不标记为已验证领取奖励。

## 持久化与异常
配置、进度、运行日志通过 Tauri 标准用户数据路径保存（macOS 使用 Application Support，Windows 使用对应用户应用数据目录），不能写入 App 包。进度记录任务开始与结束；启动时发现未结束记录则显示上次中断，不自动启动。配置损坏时提示并允许恢复默认。执行失败即停止后续任务，保留日志与可选择的恢复起点。运行中锁定本次任务计划，配置调整不影响当前执行。

## 环境与权限
执行前检查 Python、游戏窗口和点击运行条件，提供明确中文错误与权限说明。复用当前窗口校准、输入校验和等待规则。真实点击涉及的广告、商店购买、能量消耗条件继续沿用原脚本限制，在任务说明中展示。测试 App 时先执行无点击模拟，不自动运行完整游戏日常。

## 验收
1. 构建生成 .app，双击启动并显示界面。
2. 单命令模拟与每日默认模拟通过，日志可见。
3. 增删任务与选择起点影响真实执行计划；配置重启后保留。
4. 测试停止、并发启动拦截、失败阻断、异常中断恢复提示。
5. 对现有脚本运行回归测试，区分已有失败与新回归。
6. 用界面检查或截图验证主要控件；明确说明实际点击及奖励验证覆盖范围。

## Windows 扩展边界（2026-10-14 更新）
- 用户已选择 Tauri + Python 架构：使用跨平台 Web 界面、Tauri 桌面进程和 Python sidecar。接受 Rust/Web/Python 构建复杂度以保留 Windows 界面复用能力。
- 共享层：任务目录、计划配置、参数校验、进度事件和界面；执行引擎在独立进程运行，统一输出结构化事件，确保界面不阻塞。
- 平台层：游戏窗口查找、激活、边界读取、点击、拖拽与权限检查，提供最小接口。首版仅实现 macOS；Windows 后端未实现时明确提示，不尝试调用 AppleScript。

- 平台打包在对应系统构建并验证；首版仅证明 macOS 可运行，Windows 作为架构扩展能力，不作为已经支持的功能。
