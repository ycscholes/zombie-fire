# App 任务层级与共享参数设计

用户已于本次会话确认以下设计并授权实施。

- 日常任务显示为游戏底部 Tab、功能模块、具体任务三个层级；各层以实际日常执行顺序首次出现的顺序显示，叶任务顺序与现有业务目录一致。
- 日常页移除任务属性表单，保留任务启用、起点选择、执行、停止、模拟运行及日志。
- 日常任务与对应单条命令共用参数定义、默认值、可选值和持久化配置。单条命令修改属性后，日常实际执行同样使用该值，包括领取状态、数量、次数与等待时间。
- App 所有命令的领取状态默认可领取，领取数量默认 3（拟态牌库沿用既有 App 默认；机械震荡和武装降临原无数量默认，在 App 采用 3），动画状态默认已勾选；其他次数和等待参数以对应日常复合命令的定义作为共享默认。旧配置的显式选择不能被默认值覆盖。
- 本次默认规则适用于 App 日常页与 App 单条命令页。直接 CLI 入口保持已有的缺参数安全跳过行为，App 会传入配置解析后的参数；配置默认值不作为当前页面状态已观察或领取已成功的证据。
- 辅助功能和 System Events 自动化均已授权时隐藏系统提示；未授权、检查异常展开显示。实机 System Events 未运行会返回 not_checked：辅助功能已授权而自动化尚未检查时默认收起，摘要保留真实状态及展开入口，不将其标为已授权。
- 将默认领取与参数共用规则写入 SKILL.md，并同步相关说明，保留空白窗口停止等安全限制。
- 不运行真实游戏领取来验证界面修改；离线测试、构建、打包与实机业务证据分别报告。
